    -> Think of clauses like instructions given for the database.
    -> where clauses
    -> filter records based on the spectified condition where clauses can be used as comparision operator,logical operator..etc
    -> syntax:
    -> select column1,column2...
    -> from table
    -> where condition;
Group by clause
=============
The group by clause is used to grp rows having the same value in one or more columns.It is commonly used with aggregate functions such as
sum(),min(),max(),avg(),count()

Syntax:

 select column-name,aggregate-function(column-name)
from table-name
group by column;


HAVING clauses
===========
The having clause is used to filter grouped records after group by clause.it is similar to where but it is works on the group by insted of indivisual rows.
syntax:
select column-name,
agregate-function(column-name)
from table-name group by column-name having condition;

order by clause
==============
The order  by clause is used to sort the resultant in descending (ASC) or descending (DESc) order
asc---> ascending order by default.
desc---> descending order 

syntax:
select column-name
from table-name
order by column-name asc;

SELECT DEPARTMENT,
     AVG(MARKS)AS AVG_MARKS
     FROM STUDENTS
     WHERE AGE>20
     GROUP BY DEPARTMENT
     HAVING AVG_MARKS>70
     ORDER BY AVG_MARKS DESC;

SELECT DEPARTMENT,
     SELECT CITY,COUNT(*)AS TOTAL_STUDENTS
     FROM STUDENTS
     WHERE MARKS>70
     GROUP BY CITY 
     HAVING TOTAL_STUDENTS>1
     ORDER BY TOTAL_STUDENTS ;



SELECT DEPARTMENT,
     SUM(MARKS)AS TOTAL_MARKS
     FROM STUDENTS
     WHERE CITY IN ('HYDERABAD','PUNE')
     GROUP BY DEPARTMENT
     HAVING TOTAL_MARKS>100
     ORDER BY TOTAL_MARKS ;


SELECT CITY,MAX(MARKS)AS MAX_MARKS FROM STUDENTS,
     FROM STUDENTS
     WHERE DEPARTMENT='ECE'
     GROUP BY CITY
     HAVING MAX_MARKS>70
     ORDER BY MAX_MARKS  DESC;


SELECT DEPARTMENT,
     AVG(AGE)AS AVG_AGE 
     FROM STUDENTS
     WHERE CITY IS NOT NULL
     GROUP BY DEPARTMENT
     HAVING AVG_AGE>20
     ORDER BY DEPARTMENT ;
