# JOINS
===========
* A JOIN IS MYSQL IS COMBINE ROWS FROM TWO OR MORE TABLES IS BASED ON RELATED COLUMNS.
 MULTIPLE TO FETCH  THE DATA

EX: EMPLOYEE TABLE ---. EMPLOYEE RECORDS
DEPARTMENTS ---> DEPARTMENTS DETAILS.

 IF YOU WANT TO SEE WHICH EMPLOYEES BELONGINGS TO WJHICH DEPARTMENT YOU NEED TO JIN THESE TWO TABLES.

#  * WHY DO WE NEED JOINS?
TO FETCH DATA FROM MULTIPLE TABLES IN A SINGLE QUERY
TO REDUCE DATA DUPLICATES (INSTEAD OF KEEPING EVERYTHING IN ONE TABLE)
TO IMPLEMENTS RELATIONSHIP (ONE-TO-ONE,ONE-TO-MANY,MANY-TO-MANY,MANY-TO-ONE).
TO GENETATE THE REPORT ANDD ANALYTICS COMBINIG DIFFERENT DATASETS.

TYPES OF JOINS: DIFFERENT TYPES OF JOINS 
===============
1. INNER JOIN ---> IT IS MATCHED RECORDS FROM BOTH TABLES
2. LEFT JOIN (LEFT OUTER JOIN) ---> IT IS MATCHED RECORDS + LEFT TABLE RECORDS
3. RIGHT JOIN ( RIGHT OUTER JOIN) ---> IT IS RECORDS + RIGHT TABLE RECORDS
4. FULL JOIN  ----> IT IS INNER JOIN+RIGHT JOIN+LEFT JOIN
5. CROSS JOIN ---> IT IS PERFORMS CARTESIAN PRODUCT

1. INNER JOIN
===============
IT RETURNS THE ROWS THAT HEVE THE MATCHING VALUES IN BOTH VLAUES.
SYNTAX:
------
SELECT COLUMNS
FROM TABLE 1
INNER JOIN TABLE 2
ON TABLE1.COMMON-COLUMN=TABLE.COMMON-COLUMN;

2. LEFT JOIN
==================
 IT IS RETURNS ALL THE ROWS THE LEFT TABLE AND MATCHED ROWS FROM THE RIGHT TABLE. IF NO MATCH NULL VALUES APPER FOTR THE RIGHT TABLE COLUMNS.

SYNTAX:
------
SELECT COLUMNS
FROM TABLE 1
LEFT JOIN TABLE 2
ON TABLE1.COMMON-COLUMN=TABLE.COMMON-COLUMN;

3. RIGHT JOIN
==================
 IT IS RETURNS ALL THE ROWS THE RIGHT TABLE AND MATCHED ROWS FROM THE LEFT TABLE. IF NO MATCH NULL VALUES APPER FOTR THE LEFT TABLR COLUMNS.

SYNTAX:
------
SELECT COLUMNS
FROM TABLE 1
RIGHT JOIN TABLE 2
ON TABLE1.COMMON-COLUMN=TABLE.COMMON-COLUMN;

4. FULL JOIN
=================
 IT IS TO SIMULATE USE THE UNION OF LEFT JOIN AND RIGHT JOIN.
SYNTAX:
-----------
SELECT COLUMNS
FROM TABLE 1
LEFT JOIN TABLE 2
ON TABLE1.COMMON-COLUMN=TABLE.COMMON-COLUMN;
UNION
SELECT COLUMNS
FROM TABLE 1
RIGHT JOIN TABLE 2
ON TABLE1.COMMON-COLUMN=TABLE.COMMON-COLUMN;

5.CROSS JOIN
==============
IT RETURNS THE CARTESIAN PRODUCT IN EVERY FIRST TABLE WITH EVERY ROW FROM THE SECOND TABLE.

SELECT COLUMNS
FROM TABLE1
CROSS JOIN TABLE2;

TOTAL SALARY PER DEPARTMENTS;
SELECT D.DEPARTMENT_NAME,COUNT(E.EMP_ID)AS TOTAL_EMPLOYEES
     FROM DEPARTMENTS D
     LEFT JOIN EMPLOYEES E
     ON D. DEPARTMENT_ID=E.DEPARTMENT_ID
     GROUP BY D.DEPARTMENT_NAME
 
     ORDER BY TOTAL_EMPLOYEES DESC;
     
SELECT D.DEPARTMENT_NAME,COUNT(E.EMP_ID)AS TOTAL_SALARY
     FROM DEPARTMENTS D
     LEFT JOIN SALARY E
     ON D. DEPARTMENT_ID=E.DEPARTMENT_ID
     GROUP BY D.DEPARTMENT_NAME
     HAVING TOTAL_SALARY>50000
     ORDER BY TOTAL_SALARY ASC;
