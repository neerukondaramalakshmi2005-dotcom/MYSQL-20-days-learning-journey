4. Special Operators:
---------------------
IN - Match any value in a list
BETWEEN - Check if value is within range
IS NULL / IS NOT NULL - Check for null values

LIKE - Pattern matching:

Pattern		Meaning			Example		Matches
A%		Starts with A		LIKE 'A%'	Apple, Adam, A123
%a		Ends with a		LIKE '%a'	Maria, Julia, pizza
%test%		Contains test		LIKE '%test%'	testing, pretest, test123
A_C		3 chars: A?C		LIKE 'A_C'	ABC, ARC, AGE
____		Exactly 4 chars		LIKE '____'	John, Maria, Test
_a%		2nd char is a		LIKE '_a%'	Cat, Back, Happy
T_ST%		T?ST...			LIKE 'T_ST%'	TEST, TOAST, TWIST

These patterns are essential for building effective search functionality in your database applications!

5.CASE OPERATOR:
----------------
--> The CASE operator is used to add conditional logic (if-then-else) to your SQL queries. It evaluates conditions and returns values based on those conditions.

SYNTAX:
-------
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE result_default
END

EXAMPLE:
--------
SELECT name, score,
CASE
    WHEN score >= 90 THEN 'A'
    WHEN score >= 80 THEN 'B'
    WHEN score >= 70 THEN 'C'
    ELSE 'F'
END AS grade
FROM students;

OUTPUT:
-------
student_id | name    | score | grade
-----------|---------|-------|-------
1          | Alice   | 95    | A
2          | Bob     | 85    | B
3          | Charlie | 72    | C
4          | David   | 55    | F
