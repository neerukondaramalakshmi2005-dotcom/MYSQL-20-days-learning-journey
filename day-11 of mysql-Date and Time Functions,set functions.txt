MONTH() --> EXTRACT MONTH
DAY() :--> IT EXTRACT DAY AND MONTH
WEEK() --> IT EXTRACT WEEK NUMBERS
DAYOFWEEK() --> DAY OF WEEK
DATE_ADD :--> IT ADD TIME OF  DATE

 SET OPERATORS
========================
UNION -->combines results from two queries and remove duplicate rows columns must have the same number and type
UNION ALL --->combines results from two queries and include all rows,includingduplicates columns must have the same number and type
INTERSECTION--->returns rows that are common to both queries.columns must have the same number and type
---NOTE --> mysql doesnt support intersect direactly
MINUS--> returns rows from the first query that are not present in the secound query.colomns must have the same number an type   .
--note--> mysql doesnt support minus direactly

----- JOINS--
 MULTIPLE TO FETCH  THE DATA
===============
 INNER JOIN ---> IT IS MATCHED RECORDS FROM BOTH TABLES
 LEFT JOIN  ---> IT IS MATCHED RECORDS + LEFT TABLE RECORDS
 RIGHT JOIN ---> IT IS RECORDS + RIGHT TABLE RECORDS
 FULL JOIN  ----> IT IS INNER JOIN+RIGHT JOIN+LEFT JOIN
 CROSS JOIN ---> IT IS PERFORMS CARTESIAN PRODUCT
