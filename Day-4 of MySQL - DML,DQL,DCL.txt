DML (Data Manipulation Language):
---------------------------------
1.INSERT:
---------
--> Used to Add new rows/records of data into a table.
APPROACH 1:
-----------
SYNTAX --> INSERT INTO TABLE_NAME(COLUMN_NAME1,COLUMN_NAME2,....COLUMN_NAMEN)VALUES(VALUE1,VALUE2,.....VALUEN);
example --> INSERT INTO EMPLOYEES(EMPID,FNAME,LAST_NAME,AGE,DOJ,ADDRESS,DEPT)VALUES('EMP01','PRASAD','GARA',23,'2026-06-10','VIZAG','DEVELOPER');

SYNTAX to insert multiple records --> INSERT INTO TABLE_NAME(COLUMN_NAME1,COLUMN_NAME2,....COLUMN_NAMEN)VALUES(VALUE1,VALUE2,.....VALUEN),(VALUE1,VALUE2,.....VALUEN),(VALUE1,VALUE2,.....VALUEN),...;

example --> INSERT INTO EMPLOYEES(EMPID,FNAME,LAST_NAME,AGE,DOJ,ADDRESS,DEPT)VALUES('EMP01','PRASAD','GARA',23,'2026-06-10','VIZAG','DEVELOPER'),('EMP02','GAUTHAM','GANTA',22,'2026-06-10','VIZAG','DEVELOPER');

APPROACH 2:
-----------
INSERT RECORDS WITHOUT MENTION COLUMN_NAMES:

SYNTAX --> INSERT INTO TABLE_NAME VALUES(VALUE1,VALUE2,.....VALUEN);
example --> INSERT INTO EMPLOYEES VALUES('EMP01','PRASAD','GARA',23,'2026-06-10','VIZAG','DEVELOPER');

SYNTAX to insert multiple records --> INSERT INTO TABLE_NAME VALUES(VALUE1,VALUE2,.....VALUEN),(VALUE1,VALUE2,.....VALUEN),(VALUE1,VALUE2,.....VALUEN),...;

EXAMPLE -->INSERT INTO EMPLOYEES VALUES('EMP01','PRASAD','GARA',23,'2026-06-10','VIZAG','DEVELOPER'),('EMP02','GAUTHAM','GANTA',22,'2026-06-10','VIZAG','DEVELOPER');

APPROACH 3:
-----------
INSERT RECORDS WITH SOME SPECIFIC COLUMNS:

SYNTAX --> INSERT INTO TABLE_NAME(COLUMN_NAME1,COLUMN_NAME2,COLUMN_NAME3)VALUES(VALUE1,VALUE2,VALUE3);
example --> INSERT INTO EMPLOYEES(EMPID,FNAME,LAST_NAME)VALUES('EMP04','GAUTHAM','KONDA');

-------------------------------------------------------------------------------------------------------------------------
2.UPDATE:
---------
-->Used to Modifies existing records in a table by changing the values of one or more columns based on a specified condition.

SYNTAX --> UPDATE TABLE_NAME SET COLUMN_NAME = VALUE WHERE CONDITION.
EXAMPLE --> UPDATE EMPLOYEES SET LAST_NAME ='BBB' WHERE EMPID = 'EMPO3'
----------------------------------------------------------------------------------------------------------------------------
3.DELETE:
---------
-->Removes one or more existing rows from a table based on a specified condition, while keeping the table structure. Can be rolled back if used within a transaction.

SYNTAX --> DELETE FROM TABLE_TABLE WHERE CONDITION;
EXAMPLE --> DELETE FROM EMPLOYEES WHERE LAST_NAME= 'KONDA';
---------------------------------------------------------------------------------------------------------------------------------
DROP VS DELETE VS TRUNCATE
===========================

DELETE : DELETE THE RECORDS BASED ON SOME CODITIONS

TRUNCATE: DELETE ALL RECORDS PRESENT IN THE TABLE WITHOUT DELETE THE STRUCTURE.

DROP : DELETES ENTIRE TABLE ALONG WITH STRUCTURE.

DQL (Data Query Language):
--------------------------
SELECT:
-------
-->Retrieves data from one or more tables or views based on specified columns and conditions. It is the most frequently used SQL command.

SYNTAX --> SELECT * FROM TABLE_NAME;
EXAMPLE --> SELECT * FROM EMPLOYEES;
----------------------------------------------------------------------------------------------
USER CREATION:
--------------
SYNTAX --> CREATE USER 'USERNAME' IDENTIFIED BY 'PASSWORD'
EXAMPLE --> CREATE USER 'PRASAD' IDENTIFIED BY 'Prasad@2003'

DCL (Data Control Language):
----------------------------
GRANT:
------
-->Gives specific privileges or permissions (such as SELECT, INSERT, UPDATE, DELETE) to a database user or role.

SYNTAX FOR SPECIFIC PRIVILEGES --> GRANT PRIVILEGE_NAME1,PRIVILEGE_NAME2,..PRIVILEGE_NAMEN ON TABLE_NAME TO USERNAME;
EXAMPLE -->GRANT SELECT,ALTER,UPDATE,DELETE ON STUDENTS TO 'SUNNY';

SYNTAX FOR ALL PRIVILEGES --> GRANT ALL PRIVILEGES ON TABLE_NAME TO USERNAME;
EXAMPLE -->GRANT ALL PRIVILEGES ON STUDENTS TO 'SUNNY';

REVOKE:
-------
-->Removes previously granted privileges or permissions from a database user or role, restricting their access to database objects.

SYNTAX FOR SPECIFIC PRIVILEGES --> REVOKE PRIVILEGE_NAME1,PRIVILEGE_NAME2,..PRIVILEGE_NAMEN ON TABLE_NAME FROM USERNAME;
EXAMPLE -->REVOKE SELECT,ALTER,UPDATE,DELETE ON STUDENTS FROM 'SUNNY';

SYNTAX FOR ALL PRIVILEGES --> REVOKE ALL PRIVILEGES ON TABLE_NAME FROM USERNAME;
EXAMPLE -->REVOKE ALL PRIVILEGES ON STUDENTS FROM 'SUNNY';
