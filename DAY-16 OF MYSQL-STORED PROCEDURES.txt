DAY-16 OF MYSQL-STORED PROCEDURES

WHAT ARE STORED PROCEDURES?
 A STORED PROCEDURES is a named ,precompiled collection of one or more SQL statements that is  stored inside the database can be executed(called) whenever the required.insted of sending a long block of SQL code from applications every time ,applications simply calls the STORED PROCEDURES
 by name

WHY USE STORED PROCEDURES

PERFORMCE: precompiled and cached by the data bases engine soo repeated execution is faster than ending raw SQL each time
reusability: Write the logic once, call if from maybe applications for scripts
security: users can be granted EXECUTE permissions on a procedures without granting direct access to the underlying table
Reduce network traffic: A single call statement replaces many lines of SQL sent over the network.
Maintainability: Business logic is centralized in the databases so changes or made the in one place.
Consistency: ensure the same validation/business rules are applied every time 


CREATE PROCEDURE SYNTAX:
==========================
DECLIMITER//
CREATE PROCEDURE PROCEDURE_NAME(
                [ IN |OUT|INOUT] PARAMETER_NAME DATA_TYPE,.....
)
BEGIN
   --------SQL STATEMENTS / LOGIN
   -------- DECLARATION,CONDITIONS,LOOPS..ETC.
END//
DELIMITER;

ADVANTAGES
=========
Faster execution after complication 
reduce duplicates SQL.
supports transactions, loops, conditions, variables, cursor ,and exception handlers
easy maintains

Disadvantages:
==============
debugging can be difficult
vendor specific syntax
complex PROCEDURE  may become hard to maintain

IN Parameters
============
Definition:
---------
AN in parameters is used to pass a value into a stored PROCEDURE 
the procedure can use the value , but changes the made to parameters inside the procedure not returned the caller


syntax:
-----------
CREATE PROCEDURE PROCEDURE_NAME (IN PARAMETER_NAME DATA_TYPE)
BEGIN
    SQL STATEMENTS
END;

OUT PARAMETER
================
DEFINATION
------------
AN OUT PARAMETER is used to return value from a stored procedure to the caller.
the caller provides the a variable to receive the result.

stntax:
----

CREATE PROCEDURE procedure_name(OUT paramter_name datatype)
BEGIN
set paramter_name=value;
END;
