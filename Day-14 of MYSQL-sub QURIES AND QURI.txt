WHAT IS SUBQUERIES?
A sub query is a query inside another query.
It is written inside a parantisis() and its is used to outer query.
it is also called as 
inner query
nested query
inner select.

General syntax:
================
select column-list
from table
where column operator(select column from table where condition):
 
purpose of subquery:
==================
To breakdown complex problems into smaller query.
To use the result of one query as input to another.
To avoid the multiple steps (write in a single query instead of temp tables)

Types of subqueries:
================
1. Single row subquery
2. multi-row subquery
3.nested subquery
4. corelated 
5.exists/not exists subquery


1. Single row subquery
======================
single row subqueries returns exactly  is one row and  columns . they use the comparision operator like =,<,<=,>,>=,!=

characteries
===========
returns only one value.
can use single value comparisons operators

syntax:
=============

from table
where column operator (select column from table where condition):

 * Multi-Rows subquery(ANY/SOME)
=============================
multi rows are subqueries returns the multiple values or rows when the using any or some, the condition is true if the matches at least one values returned the by the subquery.

characteries
----------
returns the multiple values.
ANY and SOME are interchangeable condition is true if the value is satisfy the condition.
often used with IN>ANY>,<ANY,=ANY..ETC

syntax:
==========
 Columns from table
where column IN(select column from table where condition);

* Multi-Row subquery(ALL)
==================
The all operator means the condition must be true for all values return by the subquery.


Characteristics :
------------------

--> Condition must be true for all values in the subquery result
--> Often userd with>ALL,<ALL,=ALL,<=ALL
--> >ALL means greater than the max value
--> <All means less than the minimum values

SYNTAX:
---------
Select Columns from table
where column IN(select column from table where condition);


3. nested subquery:
==================


characterizes 
--------------

useful for complex conditions
syntax:
------

4. Corlated subquery:
=======================
corelated subquries are subquries that refrence column from the outer query . unlike the regular subquries that execute the once, corelated subquries executes once fro m each row processed by the outer query.

characterizes:
----------------
refrence column from the outer query
executes multiple times (once per outer rows).
cannot be executed the independently.
often the with EXITS,NOT EXITS

SYNTAX:
------
SELECT COLUMN

WHERE CONDTION (SELECT COLUMN

5. EXITS/NOT EXITS SUBQYERY:
==========================
EXITS is used to test whether a subquery any rows. it returns true  if the subquery returns at least one rows.false otherwise
NOT EXITS returns true if the subquery returns no rows.


characteristicS:
------------
returns TRUE/FALSE(Boolean rwsult)
more efficient that in large datasents.
often used the with co-related subquries.
stops executs as the soon as first match is found.
select clause is exits doesn't matter (often use SELECT 1).

SYNTAX:
------
SELECT COLUMN
FROM TABLE1
WHERE EXITS(SELECT 1 FROM TABLE2 WHERE CONDITIONS);

FROM TABLE1
WHERE EXITS(SELECT 1 FROM TABLE2 WHERE CONDITIONS);

-- Department Table
CREATE TABLE Department (
    dept_id INT PRIMARY KEY,
    dept_name VARCHAR(50),
    location VARCHAR(50)
);

-- Employee Table
CREATE TABLE Employee (
    emp_id INT PRIMARY KEY,
    emp_name VARCHAR(50),
    salary DECIMAL(10,2),
    dept_id INT,
    job VARCHAR(50),
    hire_date DATE,
    FOREIGN KEY (dept_id) REFERENCES Department(dept_id)
);

-- Project Table
CREATE TABLE Project (
    proj_id INT PRIMARY KEY,
    proj_name VARCHAR(50),
    dept_id INT,
    budget DECIMAL(12,2),
    FOREIGN KEY (dept_id) REFERENCES Department(dept_id)
);
