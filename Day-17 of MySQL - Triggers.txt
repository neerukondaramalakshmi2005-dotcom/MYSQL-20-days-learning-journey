Triggers:
---------
--> A Trigger is a special type of stored program that automatically executes in response to specific event INSERT,UPDATE,DELETE occurring on a specific table. unlike stored procedure.A trigger is never called directly. the database engine invokes it automatically when the triggering event happens.

syntax:
-------
DELIMITER //
CREATE TRIGGER TRIGGER_NAME
{BEFORE|AFTER}{INSERT|UPDATE|DELETE}
ON TABLE_NAME FOR EACH ROW
BEGIN
	TRIGGER LOGIC
	USE NEW COLUMN_NAME FOR INSERTED/UPDATED VALUES
	USE OLD_COLUMN_NAME FOR DELETED/PREVIOUS VALUES
END//
DELIMITER ;

BEFORE --> TRIGGER FIRES BEFORE THE TRIGGERING EVENT APPLIED TO THE TABLE.OFTEN USED FOR VALIDATION.
AFTER --> TRIGGER FIRES AFTER THE TRIGGERING EVENT HAS BEEN APPLIED.OFTEN USED FOR AUDITING/LOGGING.
NEW --> RETURNS THE NEW ROW VALUES.AVAILABLE IN INSERT AND UPDATE TRIGGERS.
OLD --> REFERES TO THE ROW VALUES BEFORE THE CHANGE AVAILABLE ON UPDATE AND DELETE.
FOR EACH ROW ---> REQUIRED IN MYSQL THE TRIGGER BODY RUNS ONCE PER AFFECTED ROW.

--------

mysql> create trigger before_insert_sal
    -> before insert on employees
    -> for each row
    -> begin
    ->  if new.salary <20000 then
    ->   signal sqlstate '45000'
    ->   set message_text = 'salary cannot be less than 20000';
    ->  end if;
    -> end //

mysql> DELIMITER //
mysql> CREATE TRIGGER TRG_BEFORE_UPDATE_SALARY
    -> BEFORE UPDATE
    -> ON EMPLOYEES
    -> FOR EACH ROW
    -> BEGIN
    ->  IF NEW.SALARY<OLD.SALARY THEN
    ->  SIGNAL SQLSTATE '45000'
    ->  SET MESSAGE_TEXT = 'SALARY CANNOT BE REDUCED'
    -> ;
    -> END IF;
    -> END //
